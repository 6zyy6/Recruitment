## 交付范围

| 核心模块 | 本轮可操作能力 | 边界 |
| --- | --- | --- |
| A 分层甄选 | HR 配置最低学历、必需技能及适用届别；逐项核对条件；生成带资料证据的复筛报告；HR 保存结论与依据 | 缺失为待核实，规则不自动淘汰；复筛为固定规则演示，未接入真实 AI |
| B 测评评估 | 可选客观笔试及自动判分；工作偏好问卷与维度报告；文本面试问答及规则评分；人工独立评价后核对本人评分及证据 | 问卷非已验证性格量表，无录用阈值；文本与辅助评分是规则演示，经理最终决定 |
| 日程视觉修复 | 重新设计月份、日期及星期层级，统一尺寸、留白和行对齐 | 不改变已有安排、改期、通知和评价规则 |

默认路径为：岗位标准确认 → 条件初筛 → 简历证据复筛 → HR 复核 → 可选问卷/笔试 → 可选文本面试 → 人工结构化面试 → 独立提交后辅助评分 → 人工决定 → Offer → 实际入职。按岗位选用环节，不要求所有候选人完成全部关卡。

## 验收标准

| 编号 | 验证任务 | 通过标准 |
| --- | --- | --- |
| V201 | 保存社招/校招筛选规则，刷新及重新登录，输入非法字段 | 合法配置服务端保存；非法输入明确拒绝；未启用条件不显示失败；报告能识别采用的标准与版本，原报告不静默改写 |
| V202 | 用满足、不符及缺失学历/技能/届别样例核对 | 逐项显示要求、实际信息和状态；未知为待核实；明确不符也不自动淘汰 |
| V203 | 生成简历复筛报告 | 要求、资料片段、缺失/核实问题及规则来源可核对，不编造经历；报告显著标注规则演示及未接入真实 AI |
| V204 | HR 保存补资料、推进或结束结论，缺依据提交 | 记录人工结论、依据、作者及时间；必要依据缺失被拒；可与报告不同；通过需当前核对及复筛报告，待核实或不予推进可直接留因处理 |
| V205 | 提交正确、错误及未完成笔试答案 | 按标准答案准确判分；报告展示题目、答案、分数及解释；未完成有提示；分数不自动改变招聘结果 |
| V206 | 完成或不启用工作偏好问卷 | 展示维度及解释，无心理诊断、优劣标签或总分淘汰线；可跳过未选环节 |
| V207 | 提交充分和不足的文本面试回答 | 维度评分有固定规则、版本及回答片段；不足为未观察/待补充，不虚构证据；不冒称真实模型或语音视频能力 |
| V208 | 面试官提交前从页面及 API 请求辅助评分，之后提交人工评价 | 提交前不可见且接口不泄露；提交后按权限查看；辅助结果不覆盖原人工分数 |
| V209 | 不同角色、岗位、任务及同人多岗读取报告 | 服务端权限生效，无权资料不返回，同人不同投递不串用结果 |
| V210 | 检查复筛、文本面试和辅助报告 | 醒目标注规则演示及来源；无伪造模型调用或发送回执；不以演示通过证明真实 AI 效果 |
| V211 | 保存规则、结论、作答与报告后刷新/重登；尝试高分跳过人工门槛 | 数据仍按权限可读；冲突失败不显示成功；无分数自动推进、淘汰或录用，原经理与 Offer 门槛保留 |
| V212 | 1024/1280/1920 宽度检查面试列表及操作 | 月/日/星期层次清楚，无重复“日”或逐字折行，卡片尺寸及内容对齐，无页面横向溢出，原操作可用 |

自动化验证规则、权限和保存，浏览器验证可操作性与视觉。验证记录须说明实际通过及未执行项，服务重启、备份、容量和真实 AI 评测不能由一次刷新替代。

## 执行与交接

1. 同步主计划与需求、技术、验收子文档，检查新增能力与原范围无冲突。
2. 实现规则、证据及 HR 复核，验证配置校验、未知信息和人工决定。
3. 实现测评作答、确定性评分及独立人工评价后的辅助报告，验证证据与权限。
4. 修复日期卡并走查三个桌面宽度，回归受影响的已有流程。
5. 交付更新入口、源码、测试/浏览器记录、演示路径与明确限制。

V201–V212 为本次发布门槛；原 AC01–AC26、NF01–NF03 保留为完整产品合同，未执行不自动通过。真实 AI、岗位适用性已验证的性格工具、外部考试、语音转写、监考、候选人门户与渠道/消息集成另行规划。全链路仍覆盖需求、渠道、投递、甄选、录用、入职、人才经营、分析与资料治理，不因本轮选择两个模块而删去。
